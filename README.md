### 💻 What am I currently working on?
- [TopStats.gg](https://topstats.gg) (formerly DBL Statistics) -- Analytics for bots listed on [Top.gg](https://top.gg). Next.js web app, Expo React Native mobile app and Fastify API in a TypeScript monorepo, backed by TimescaleDB and run on self-hosted Docker Swarm.
- [TopStats Analytics](https://docs.topstats.gg/docs/analytics) -- Event analytics for game servers, bots and web apps. Official SDKs for Node.js, Python, Go, Rust, Java, Kotlin, .NET, Swift, PHP, Ruby, Elixir and Lua, plus integrations for Minecraft, Roblox, FiveM, CS2, Garry's Mod, Rust and Unturned. See [top-stats](https://github.com/top-stats).
